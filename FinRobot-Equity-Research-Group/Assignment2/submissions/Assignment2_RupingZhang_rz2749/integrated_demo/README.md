# Integrated Demo

This folder contains HTML reports generated through the FinRobot report pipeline.

These HTML files are included as an extra demo to show that my Assignment 2 enhancement can be integrated with FinRobot's official HTML report renderer.

The folders include:

- ACR-enhanced HTML reports for the required companies.
- Baseline HTML reports used for comparison.

The ACR-enhanced reports use the final workflow:

Analyst = Claude  
Critic = GPT/OpenAI  
Reviser = Claude

Some HTML reports may show sections such as “Sensitivity analysis not available” or “Catalyst analysis not available.” These are optional advanced FinRobot modules that require extra structured inputs, and they are not the core focus of this assignment.

The main purpose of this folder is to provide visual evidence that the improved ACR workflow works inside the FinRobot pipeline.
