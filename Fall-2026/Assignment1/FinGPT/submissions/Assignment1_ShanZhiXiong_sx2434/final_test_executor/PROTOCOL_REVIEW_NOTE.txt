This protocol does not claim text or accuracy invariance. Test interpretation must disclose the change. Probe outputs do not replace or augment the primary validation cohort.

Llama16 failed OOM with zero saved outputs; the proposal retains its fully validated batch8. The parent holds one GPU lock while each model runs in its own OS process. Each child must exit before the next launches. All three full native prompts must fit the predeclared validation-derived maximum: Qwen3517, DeepSeek3276, Llama3272 tokens. A batch containing any over-envelope row is generated one row at a time for both base and adapter. The input-length-only rule is frozen before test access; no row is removed and no prompt is clipped. These batches use different serving sizes and must be disclosed. Exceeding the hard4224 prompt-token limit still aborts before all GPU loading; source/schema/technical failures may also abort after authorized access. Such failures preserve evidence and require a new protocol and new approval; no automatic resume or tuning is permitted. Reserved and allocated memory guards both apply.
