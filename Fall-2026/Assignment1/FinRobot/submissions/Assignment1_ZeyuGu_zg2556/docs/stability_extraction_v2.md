# Stability measurement protocol v2

`scripts/stability_audit_v2.py` uses version `independent-stability-extractor-v2-source-units`. The underlying three writer generations remain unchanged. The previous measurement calls under `audits/stability/NVDA` are preserved, including their failures and costs. This repair changes the measurement transport, not the original generated reports.

All eight saved section texts are split into immutable sentence-sized units by `grounding_audit.source_units`. Every unit includes its integer identifier, exact Unicode text, character offsets and section hash. The extractor returns only a section and `source_unit_id` for each rating/target, and a `source_unit_id` plus taxonomy category for each risk in the risk section. It never reconstructs a quote. Program code supplies exact text and offsets. The full prompt/unit inventory is saved for each extraction attempt.

Ratings must use a literal standard phrase in the selected unit. Numeric targets must match a complete literal numeric token, not a substring or calculated amount. Currency and horizon must be literal in the same unit or marked `not_stated`. A dollar sign is not silently interpreted as USD. External analyst views, writer recommendations and ambiguous attribution remain separate. Absent, conflicting or incomparable recommendations produce N/A rather than inferred values. Fixed FMP headline fields are measured separately; their zero variance describes input reuse, not LLM stability.

The top-three risk measure selects the first three distinct taxonomy categories by the position of their earliest source unit. If multiple categories occur within the same unit, their true order is unresolved; ties use the fixed taxonomy order stated in the prompt. This is a textual-order measure, not importance ranking. Pairwise Jaccard measures set overlap; Kendall tau is calculated only on shared categories and is N/A when fewer than two are shared. The fixed taxonomy can inflate apparent agreement, and extraction completeness and classification remain machine judgments. No human review is claimed.

Before extraction, the script validates all 24 actual writer calls: distinct provider response IDs/call IDs/wire responses, successful HTTP responses, matching typed and wire content, identical input and actual request contracts, timestamps, token use and runtime. The measurement calls are additional calls and are accounted for separately.

Every paid extraction uses an immutable `calls/<run_id>/attempt_NNN` directory. Successful attempts are selected by a small pointer file. `--resume` validates the extractor version, schema, model, settings, provider URL, original runs and all source-prompt hashes before reusing successful attempts. Failed/incomplete attempts are retained; one new attempt is allowed per resumed execution when needed. A completed v2 extraction can be replayed into a new output directory with `--offline-extractions`, using no credentials, network or new model calls. Legacy quote-based responses cannot be replayed as v2 observations.

The unit tests use explicitly synthetic temporary fixtures only, covering exact source reconstruction, invalid IDs, numeric substring rejection, literal context, external attribution, within-unit ties, failed-attempt preservation, successful resume, contract changes and the offline network prohibition. They are not experimental evidence. Genuine v2 statistics are produced only after the three new measurement calls finish.
