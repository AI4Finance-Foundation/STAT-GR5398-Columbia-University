# WRDS exports and public-source decision

The user authenticated in the Codex browser on October 11, 2026. Two Compustat web queries completed: annual fundamentals (query 11774671, 31 rows) and security daily (query 11774673, 8,510 rows). The downloaded CSV and SQL files are preserved outside the course submission in a private local cache. Only file hashes, query scope and counts appear in the submission. No downloaded WRDS financial values were supplied to the writer, verifier, evaluator or Codex model.

After these exports, inspection of the [WRDS terms of use](https://wrds-www.wharton.upenn.edu/users/tou/) identified a prohibition on automated website queries; automation is instead permitted on WRDS Cloud. Automated website querying stopped at that point. The [WRDS AI policy](https://wrds-www.wharton.upenn.edu/pages/about/ai-policy-on-chatgpt-and-other-generative-ai-tools/) also requires protected services and appropriate data-protection terms for the applicable vendor exceptions. The user confirmed that no institution-approved protected service was available and instructed the project to continue with public materials. The earlier unsuccessful local PostgreSQL connection is not evidence of missing web dataset entitlement.

AVGO and QCOM therefore use frozen public SEC filings/companyfacts for annual statements and shares, a literal recent 10-Q table for the limited news input, and a separately saved Yahoo Finance public chart response for price. FMP peer snapshots are reused. This is a disclosed data-availability compatibility adapter, not a WRDS-backed replication or a second research improvement. There is no attempt to defeat FMP's denied entitlement. Missing historical subject market multiples remain unavailable; the upstream valuation fallback of 12x with a 3x standard deviation is expressly labeled as an assumption. The formal before/after experiment remains on NVDA, AMD and INTC with unchanged frozen FMP inputs.

Private WRDS files are not needed for offline reproduction, are not included in the public patch/PR, and are not included in model prompts. An authorized user may perform a separate local comparison, but no such value-level comparison has been claimed here.
