# v3横截面排名目标：测试期前研究协议

登记日期：2026-11-19（America/New_York）

## 唯一主要训练变化

在v2的特征、时间可知性门槛、训练分区预处理、六个基础模型、stacking、随机种子和组合参数上保持不变。将每个已成熟的未来绝对收益 `y_return`，转换为同一 `datadate`、同一bucket内部的百分位排名 `y_target`，再训练回归模型。目标范围为0至1。

这样做是因为组合最终需要股票的横截面排序，并不需要预测精确的绝对收益率。转换只在同一财务日期和bucket内使用已经成熟的标签；一个日期的全部行属于同一个时间分区。

课程分数、v2分数、估值模块、回测器、交易成本、选股数量、仓位上限和full择时均不得改变。所有输出必须写入独立的 `rank_target_v3` 目录。

## 执行顺序

1. 先试训2019-05和2019-06，检查候选键、截止日期、有限数值和输出差异。
2. 通过后训练2017-01至2026-11全部119个月。
3. 只运行dev和val的A/B，尚不运行test或forward。
4. 用下列预先登记标准决定是否冻结v3进入一次最终test。
5. 若进入，写下冻结记录后只运行一次 `test --ablation --timing full`；随后运行一次短forward作描述，不再修改v3。
6. 无论结果好坏，与同环境未改原版、v2完整比较并保留。

## 进入最终test的标准

以下四项必须同时满足：

- 验证期A累计收益不低于v2的11.85%。
- 验证期A Sharpe不低于v2的0.342。
- 开发期A累计收益不低于v2的177.92%，即相对v2最多降低10个百分点。
- 开发期与验证期A的年换手均不超过对应v2的125%。

最大回撤作为重要风险证据完整报告，但不单独决定准入，以免为了一个阈值隐藏收益和波动的共同变化。若任一准入条件失败，v3不运行新的test，最终在v2与此前版本中选择；这仍算完整执行本协议。

## 解释限制

课程test和短forward在此前研究中已经查看，不能重新变成严格盲测。即使v3通过准入并在test表现更好，也只能视为回顾性扩展证据。真正的新样本需要课程数据截止日之后的未来数据。
