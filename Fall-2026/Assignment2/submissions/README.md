# Please upload your code and report HERE!

Teams of up to 3 hand in **one** folder, named after every member's UNI:
`Assignment2_UNI1_UNI2_UNI3` (e.g. `Assignment2_jd1234_jl5678`). If you work alone, use
`Assignment2_Name_UNI` (e.g. `Assignment2_JaneDoe_jd1234`). Put everything inside it, and list
each member's name, UNI and contribution in its `README.md`. Do **not** create a new branch, and do **not** commit the
course data bundle.
