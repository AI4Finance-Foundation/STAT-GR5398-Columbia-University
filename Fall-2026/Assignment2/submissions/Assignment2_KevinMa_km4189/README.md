## Reproduction (pre-TEST)

Use Python 3.11+ and the official data bundle described in the Assignment 2 README. Unzip it into `Fall-2026/Assignment2/source_code/data/` locally, not in Git. Install the dependencies with `python -m pip install -r requirements.txt` from this submission folder. For offline training, install a compatible CPU PyTorch separately; the final Windows training environment recorded NumPy 2.4.6, pandas 2.3.3 and PyTorch 2.15.0+cpu. Other dependency versions were not captured in the supplied manifest. Cross-platform bitwise equality is not guaranteed.

From this folder, run:

```sh
python reproduce.py
```

This checks hashes against the original local course snapshot, copies the required course files and data into a disposable working directory, installs the submitted timing module into that copy, runs the official automatic check, and reproduces DEV and VAL standalone and A/B/C/D results in `reproduced_pretest/final_28/`. It does not modify the checked-out official source or run TEST. Use `--data-dir PATH` if the course data is elsewhere; use `--out PATH` for a new output directory. `python reproduce.py --check-only` checks compatibility without backtesting.

To additionally verify both offline model banks and rerun all DEV volatility sensitivity configurations, the 25%/28% VAL comparison and early 22% internal variants:

```sh
python reproduce.py --verify-training --sensitivity --out reproduced_training
```

All subprocesses use `PYTHONHASHSEED=5398`. The archived early experiments were run before the fixed hash seed was adopted; small differences in portfolio execution can occur. The early internal variants use 22% trained banks and fixed-weight changes (including the 25% sensitivity variant); they are configuration comparisons, not pure causal component attribution. The separate four-target experiment retrains Q for each target. The 25% and 28% final VAL comparison was repeated with the fixed seed. The final 28% DEV/VAL numbers were regenerated after exact local retraining.

`train_timing.py --course-root . --verify` is the standalone training-verification command when run inside a prepared course-code working copy. Its ordinary mode regenerates and embeds weights into that copy; do not use ordinary mode on the frozen submission for official TEST. The pre-TEST automatic check transcript is included. The supplied `output/` preserves final official DEV/VAL CSVs, eight A/B/C/D equity/trade/stat records, training manifests and NAV, and early experiment summaries. The two sensitivity summary CSVs are transcribed from the recorded terminal results, not separately generated by the official evaluator. The early internal CSVs are the original experiment outputs.

## Reproducibility and limitations

`course_fingerprints.json` records source SHA256 (LF-normalized) and data SHA256 from the original experiment bundle. This allows additions to the public framework that are not used by the experiment while detecting changes to existing required files. No course data, API keys, cached environments, or other students' submissions are included. The wrapper is a new submission-only helper; the timing model and trainer are unchanged from the verified final files. The official engine has incomplete historical high-yield credit coverage, a constant historical sentiment factor, and evolving sector breadth coverage. BAA10Y is a proxy, not equivalent to high-yield OAS. Lagged macro values do not eliminate possible vintage/revision bias. Selection-NAV rewards approximate exposure effects rather than exact portfolio fills. Fixed seed improves repeatability but is not a proof of determinism across dependency versions.

The final configuration Git SHA, official TEST outputs/log, research report PDF and published Medium URL will be recorded after preregistration and the authorized TEST evaluation. No TEST has been run as of this package; the official pre-TEST checker reports zero logged runs. Do not delete or rewrite TEST logs. The course's two official evaluation scripts each log a TEST invocation; confirm the intended counting convention before proceeding.
